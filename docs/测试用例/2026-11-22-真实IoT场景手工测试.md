## 2 操作方法与判定

1. 打开测试地址，等待输入框可输入；需要语音测试时允许麦克风。
2. 先在“家庭设备”点“刷新”，核对三台设备；不要用旧的主卫／浴缸示例代替下文提示词。
3. 每句只发送一次，先观察卡片或最终答复；20秒出现云端超时提示时记录失败。若需复核，另记一次，不覆盖首测。
4. 控制卡出现后核对数量、品类、标签和设备号；本轮点卡之前不得下发，点卡之后只允许一次对应控制。
5. 在“安全审计”查看实际 cmdList、平台回执和下发次数；同时现场核对硬件动作。不要只按助手正文判成功。
6. 知识、未适配、否定和歧义用例要有明确反馈；最终答复后额外观察4秒，确认无控制卡和下发。
7. 开关测试记录原始状态并在结束后恢复。电源关闭放在最后；冲水、暖风、翻盖、脚触、润瓷需有人在现场观察。
8. 将结果写入 JSON 的 observed，或在下表“结果”栏填写：通过／模型未调用／识别错误／筛选错误／平台拒绝／真机未动作／反馈错误／未测。

**功能通过**：语义正确 → 候选正确 → 点卡一次 → 字段正确 → 平台真实受理 → 目标硬件动作正确。平台 HTTP 200 但业务拒绝、正文虚报成功、没有最终反馈都不能判通过。

## 3 先跑的提示词

每行是一条用户原话，逐条输入；“打开夜灯”分别重发一轮选择马桶、一轮选择镜柜：

```text
打开浴霸暖风
关闭浴霸暖风
打开马桶夜灯
关闭马桶夜灯
打开镜柜夜灯
关闭镜柜夜灯
打开夜灯
怎么打开浴霸暖风
打开浴霸夜灯
打开主卫马桶夜灯
打开浴缸进水
```

正常控制候选：暖风仅浴霸1台；马桶夜灯仅马桶1台；镜柜夜灯仅镜柜1台；未说品类的夜灯为马桶＋镜柜2台。知识问答、未适配功能和不存在的位置不应拉起全设备卡。
